# 商品详情可视化编辑（试点）

## 目标

内容中心 → 商品详情 → 点「编辑」后，在真实详情页预览上直接点选改文案与图片，所见即所得。

## 交互

1. 顶部可折叠「基础设置」：名称、标识、分类、封面、列表卖点、发布开关、关联硬件、列表按钮与少数跳转 URL。
2. 下方为与前台一致的详情预览；文字点击即可改；图片点击上传替换。
3. 「发布上线」仍走现有 draft + publish API，保存后回列表。

## 实现

- 抽出共用 story 渲染（前台与后台共用），后台模式加 `data-edit-path` / `data-edit-image`。
- 仅试点商品详情；方案/新闻暂不改。
