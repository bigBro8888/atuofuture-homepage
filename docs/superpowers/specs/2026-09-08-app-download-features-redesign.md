# App 下载页核心能力区改版设计

## 目标

重做 App 下载页“四大核心能力”区块，弱化现有横幅和普通白卡片的模板感，形成更有品牌识别度的深蓝科技视觉，同时让运营人员能在后台配置卡片内容与强调色。

## 前台设计

- 区块采用浅灰蓝背景和左对齐标题，不再使用独立白色横幅及厚重阴影。
- 标题上方增加固定英文眉题 `CORE CAPABILITIES`，配合蓝色短线作为视觉锚点。
- 四张能力卡在桌面端保持四列：
  - 第一张默认使用深蓝渐变重点样式。
  - 其余卡片使用白色半透明表面、细描边和轻柔阴影。
  - 每张卡显示两位序号、发光图标、标题和描述。
  - 悬停时轻微上移，并增强阴影和边框颜色。
- 卡片强调色通过 CSS 自定义属性驱动，用于图标、序号、边框和柔光效果。
- 延续现有移动端规则：移动端不展示该区块，不改变下载流程。

## 后台设计

- 保留区块标题、副标题配置。
- 四张卡片继续配置图标、标题和描述。
- 每张卡片新增“强调色”选择，提供深蓝、青蓝、紫色、橙色四种预设。
- 后台卡片编辑器改为带颜色状态和图标预览的卡片式布局，使配置项与前台一一对应。
- 未保存强调色的旧数据由服务端补齐默认值，兼容线上已有 `store.json`。

## 数据与兼容

- `features.items[]` 新增 `accent` 字段，取值限定为 `blue | cyan | violet | amber`。
- 服务端读取旧数据时按卡片序号补默认强调色。
- 前台仅把白名单中的强调色映射为样式类，不直接拼接任意 CSS。
- API 路径和发布流程保持不变。

## 验证

- 单元测试覆盖旧配置升级和强调色保存/发布。
- 执行 `npm test` 与 `npm run build`。
- 浏览器验证前台视觉和后台四张卡片的强调色配置。
- 发布到 `/var/www/mydoc/atuofuture` 后重新构建，并验证线上页面与 API 返回正常。
